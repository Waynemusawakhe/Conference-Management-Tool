# Staging test accounts

Use these role-specific accounts to test the dashboards:

| Dashboard | Email |
| --- | --- |
| Organiser | `organiser@conference.local` |
| Reviewer | `reviewer@conference.local` |
| Author | `author@conference.local` |
| Attendee | `attendee@conference.local` |

Passwords are intentionally not stored in this repository. Obtain them through
an approved private channel or set local test credentials outside version
control. Do not reuse these test accounts in production.
